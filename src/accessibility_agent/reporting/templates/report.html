{{ group.grouper|replace('_',' ')|capitalize }} {{ group.list|length }} areas {% if group.grouper in ['navigation_background_requests_blocked', 'interaction_background_requests_blocked'] %}

The loaded page was scanned, but some background requests were blocked by the crawl policy. This can affect dynamic content. Review the page and allow only required request URLs before retrying.

{% elif group.grouper == 'authentication_origin_not_trusted' %}

The sign-in redirect was stopped by the scanner's origin policy. Standard OAuth sign-in redirects back to the application are detected automatically. For other trusted sign-in providers, add the origin shown below using --auth-origin or authentication.allowed_origins.

{% elif group.grouper in ['user_input_required', 'user_input_timeout', 'user_input_cancelled'] %}

The application required a dialog or setup choice before crawling could continue. Run a visible scan with --assist-input, complete the application's controls, and confirm in the terminal.

{% elif group.grouper == 'replay_diverged' %}

The page changed when the crawler tried to return to it. Retry with stable test data or configure ignore_selectors for changing content. Safe links can now be opened directly when replay diverges.

{% elif 'budget' in group.grouper or group.grouper == 'scan_interrupted' %}

The scan reached a configured limit or was interrupted. Increase the relevant crawl limit and run again.

{% elif group.grouper == 'policy_unknown' %}

The control did not match the active interaction policy.{% if report.configuration.get('test_environment', false) %} Testing mode was selected, but this target still lacked supported click semantics or a supported destination.{% else %} On an authorized QA site with test data, --test-environment permits unfamiliar buttons and custom click targets without application-specific names.{% endif %} Review the control manually if it remains untested.

{% elif group.grouper.startswith('policy_') %}

This control was excluded by a safety or destination restriction. Testing mode does not disable destructive-action, submission, download or origin guards. Review the recorded reason before changing any explicit allowance.

{% elif group.grouper == 'page_readiness_timeout' %}

The page was still loading or changing when the readiness wait expired, so it was not scanned. Check the waiting reasons below; adjust the readiness timeout or configure the application's ready element and loading indicators.

{% elif group.grouper in ['page_changed_before_scan', 'page_changed_during_scan'] %}

The page resumed loading or changed around the accessibility checks. This state has no accepted scan results. Retry after the application settles or configure its ready element.

{% elif 'Timeout' in group.grouper or group.grouper == 'state_unstable' %}

The page did not become ready within the configured wait. Check page availability and adjust navigation or stability timeouts.
